# Product Overview

**Jostrel** is a Nostr Relay implementation written in Java using Spring Boot.

## What is Nostr?

Nostr (Notes and Other Stuff Transmitted by Relays) is a decentralized protocol for social networking and communication. Relays are servers that store and forward messages between clients.

## Project Purpose

This project implements a Nostr relay server that:

- Accepts WebSocket connections from Nostr clients
- Stores and retrieves events (messages, posts, etc.)
- Manages subscriptions and filters
- Provides real-time message broadcasting

## Key Features

- WebSocket-based communication following Nostr protocol
- Event storage and retrieval
- Subscription management with filtering
- Real-time message relay between clients
